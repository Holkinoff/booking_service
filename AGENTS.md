Вся бизнес-логика и ограничения представлены в файле TASK.md. Перед выполнением любой задачи обязательно с ним сверяйся.

Стек: 
- Язык: Python 3.11+
- Веб-фреймворк: FastAPI
- ORM: SQLAlchemy 2.0
- Миграция БД: Alembic
- Брокер: RabbitMQ
- Кэш: Redis
- Инфрастуктура: Docker Compose

Правила:
- Используй асинхронный код
- Используй строгую типизацию
- Не генерируй миграции БД кодом, только через миграции Alembic
- Обязательное логирование (JSON) с сквозным идентификатором запроса/события между сервисами.
- Защита от дублирования запросов на уровне БД, а не только кода.
- Использование Idempotency-key для предотвращения дублирования запросов
- Используй паттерн transactional outbox для событий и ретраи с задержкой и dead-letter очередью/топиком для сообщений, которые не удалось обработать.
